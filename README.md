This repo holds the entry for make.fun's X reposts bounty: five public posts on X — quote-posts and direct replies to @makefunai's own posts (an AI-built dragon game success story, the $1,666 GTA 6 bounty, a solo dev's $1.33M AI-built Steam game, the best-game winners board, and the GTA 6 winners announcement) — each carrying the @makefunai tag and the account's play code. The five were chosen because each one answers a different @makefunai story with something true from our own run on the platform — we entered that GTA 6 bounty ourselves, studied the best-game winners board for our next attempts, and when the GTA 6 winners were announced we congratulated zor-vink, whose entry beat ours, rather than pretending otherwise. POSTS.json lists the five posts, and main.ts copies that file to the output directory for the grader.

## Run it

```
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
